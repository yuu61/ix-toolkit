# 系列間差分の読み方

無印の設定を IX-R/IX-V に移す場合、IX-R/IX-V への投入案を照合する場合、
コマンドの改名・廃止・モード変更を調べる場合に読む。
`<manuals>` は ix-manual の探索順で決めたマニュアルのルート。

## 索引と根拠

`<manuals>/ix-r/diff.tsv` は次の列を持つタブ区切りの対応表。

```text
kind / ix / ix-r / source / ref_ix / ref_ixr / note
```

コマンドの先頭語で候補を探し、`ix` / `ix-r` 列を照合する。
実際の設定値と索引のパラメータ名は異なるため、設定行全体の完全一致だけで探さない。
`absent` の行は `ip pim *` のようにコマンド群を表す。
削除する `no` 形は基になるコマンドも調べ、対象系列の crm で削除構文を確認する。

| `source` | 根拠と扱い |
|---|---|
| `ch8` | IX-R 機能説明書「IXシリーズとの差分」の表。`ref_ixr` が出典。`ref_ix` は対応する無印 crm の項目で、空の場合もある |
| `derived` | 両系列の制限事項を読み比べて導いた差。`ref_ix` と `ref_ixr` の両方を確認する。導出時の版と手元の版が異なれば出典を読み直す |
| `setdiff` | 両索引の集合差による候補。改名や索引化の差もあり得るので、非対応の断定には使わず、対象系列の索引・本文を確認する |

`ref_ix` / `ref_ixr` は `crm:` または `fd:` に各冊子の `source` が続く。
例: `crm:p765`、`fd:00_main/13_command_diff.html#id10`。
指定された冊子の索引で出典を探し、該当本文へ進む。PDF のページ内の表や注記は本文の出典リンクも使う。

## 設定案への反映

| `kind` | 意味と扱い |
|---|---|
| `renamed` | 改名。`ix-r` 列を手がかりに対象系列の構文を確認して置き換える（無印 `show logging` → IX-R `show syslog`） |
| `moved` | 登録モードの移動。コマンドを適切なブロックへ移す（`http-server ip enable`: 無印のグローバル → IX-R のインタフェース） |
| `removed` | 廃止。旧コマンドを案から外し、`note` に統一先があれば確認する。代替がなければ要件を満たす方法を検討する |
| `limit` | 一部機能が非対応。`note` の適用条件を確認し、その条件に当たる設定を案から外す。コマンド全体の廃止と混同しない |
| `range` | デフォルト・設定範囲の変更。値を確認する（`ip max-route`: 無印で使える `unlimited` は IX-R で廃止） |
| `changed` | パラメータ・オプションの変更。入力形式を確認する（`ipsec policy`: 無印の `in` / `out` に当たる方向指定が IX-R で削除） |
| `absent` | コマンド群が対象索引に無い。`source=setdiff` の候補として、個別の対応を本文で確認する |

差分表は構文の置換スクリプトではない。特にモード移動・パラメータ変更は、
対象系列の crm と fd の設定例を確認して適用する。
`derived` の制限に置き換え先があっても、元の機能を同じ意味で実現できるとは限らない。

該当がなければ両系列の索引・本文へ進む。差分表は網羅的でなく、
「差分表に無い」は「同じ構文・動作」の根拠にならない。
対応表が無い場合は不足を伝え、両系列の本文があれば直接比較する。

回答には対応するコマンド・モード・条件、`kind` / `source` と参照した出典を添える。
機器への投入は ix-configure の対象・設定行・永続化の確認に従う。
